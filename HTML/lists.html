Списки

Нумерованный список ― Ordered List

Создается дискриптором <ol>.

  1. Элемент 1;
  2. Элемент 2;
  3. Элемент 3;
  4. Элемент 4;
  5. Элемент 5;

Маркированый список ― Ordered List

Создается дискриптором <ul>.

  • Элемент 1;
  • Элемент 2;
  • Элемент 3;
  • Элемент 4;
  • Элемент 5;

Элементы списка ― ListItems

Как в нумерованном так и маркированном списке элементы создаются дискриптором <li>.

Списки определений ― Definitions List

Создается дескриптором <dl>.Каждый элемент списка описывается двумя дескрипторами: <dt> ― Desription Term и <dd> ― Desription Details.

Нумерованый список
Каждый элемент такого имет точный порядковый номер.
Маркированый список
Каждый элемент такого списка обозначен каким-то символом;
Список определений
Каждый элемент такого списка вводит понятие и дает ему определение;

Вложенность

Списки можно вкладывать друг в друга как угодно, но вкладывать список не посредственно в другой список запрещено! Список можно вкладывать только в элемент другого списка!!!
