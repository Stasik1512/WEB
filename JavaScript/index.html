JavaScript

Переменные

Переменную можно объявить при помощи ключевого слова var, let, const

var
объявляет глобальную переменную, независимо от области видимости, в которой она объявлена;
let
объявляет локальную переменную, такая переменная существет только в той области видимости, в которой она объявлена;
const
объявляет локальную константу;
